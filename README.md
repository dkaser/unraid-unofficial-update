# Unofficial Update Plugin for Unraid

Updates Unraid 7.2.8/7.3/7.4 to PHP 8.4.27 and updates the ca-certificates package to remove the eMudhra certificates.

## Installation Instructions

Copy and paste the following path into **Plugins** -> **Install Plugin** within the WebGUI:

`https://raw.githubusercontent.com/dkaser/unraid-unofficial-update/main/plugin/unofficial-update.plg`
